1준비물 확인

메모리가 가장 중요합니다. 16GB는 최소, 32GB를 권장합니다.

CPU4코어 이상
메모리최소 16GB · 권장 32GB
디스크여유 170GB 이상 (이미지 압축 약 23GB → 해제 후 53GB+)
운영체제Windows(WSL 2) · macOS · Linux
처음 내려받기에 시간이 오래 걸립니다. 유선 인터넷과 넉넉한 시간을 준비하세요.

2Docker 준비

Windows

  1. Docker Desktop을 설치하고, 엔진은 WSL 2를 씁니다 (Hyper-V 아님).
  2. 사용자 폴더(C:\Users\내이름)에 .wslconfig 파일을 만들고 아래 내용을 넣습니다.
[wsl2]
memory=24GB
localhostForwarding=true
  1. PowerShell에서 wsl --shutdown 실행 후 Docker Desktop을 다시 켭니다.
  2. Docker Desktop 설정에서 CPU 4 · 메모리 16GB 이상 · 디스크 170GB 이상을 줍니다.

macOS

Docker Desktop 설정에서 CPU 4 · 메모리 16GB · 디스크 170GB를 할당합니다.

Docker Hub 로그인

이미지를 받으려면 Docker Hub 계정이 필요합니다.

docker login

3이미지 받기 · 처음 실행

<TAGNAME>에는 Docker Hub의 sapse/abap-cloud-developer-trial 페이지에서 최신 태그를 확인해 넣습니다.

docker pull sapse/abap-cloud-developer-trial:<TAGNAME>

Windows · macOS에서 처음 실행

docker run --stop-timeout 3600 -i --name a4h -h vhcala4hci -p 3200:3200 -p 3300:3300 -p 8443:8443 -p 30213:30213 -p 50000:50000 -p 50001:50001 sapse/abap-cloud-developer-trial:<TAGNAME> -skip-limits-check -agree-to-sap-license

Linux에서 처음 실행

docker run --stop-timeout 3600 -it --name a4h -h vhcala4hci sapse/abap-cloud-developer-trial:<TAGNAME> -agree-to-sap-license
호스트 이름은 반드시 vhcala4hci 입니다. 다른 이름이면 시스템이 시작되지 않습니다.

로그가 멈추고 CPU 사용량이 내려가며 메모리 증가가 멈출 때까지 기다린 뒤 접속합니다.

끄고 다시 켜기

# 끄기 (노트북을 그냥 끄면 작업이 날아갈 수 있음)
docker stop -t 7200 a4h

# 다시 켜기
docker start -ai a4h

4SAP GUI로 접속

SAP Logon에서 새 연결(사용자 지정 시스템)을 만들고 아래 값을 넣습니다.

항목값
Application Serverlocalhost (3200 포트를 열었을 때)
Instance Number00
System IDA4H
Client001 개발 · 000 관리
UserDEVELOPER
Password버전마다 다릅니다 — 공식 문서(아래 출처)에서 사용 중인 버전의 초기 비밀번호를 확인하세요
처음에는 트랜잭션이 느립니다. 프로그램을 처음 열 때 로드가 생성되기 때문이며, 두 번째부터 빨라집니다.

5ADT(Eclipse)로 접속

CDS View · RAP 실습은 ADT에서 합니다.

  1. Eclipse를 설치하고, SAP Development Tools 업데이트 사이트에서 ABAP Development Tools를 설치합니다.
  2. File → New → ABAP Project를 선택합니다.
  3. SAP Logon에 만든 A4H 연결을 고르거나, 서버 localhost · 인스턴스 00 · SID A4H로 직접 입력합니다.
  4. Client 001, User DEVELOPER로 로그인하면 프로젝트가 생깁니다.
ADT 설치 화면과 메뉴 이름은 Eclipse · ADT 버전에 따라 조금씩 다릅니다.

6라이선스 갱신 (3개월마다)

이미지에 들어 있는 ABAP 라이선스는 3개월짜리입니다. 만료 전에 무료 데모 라이선스로 바꿉니다.

  1. SAP* 사용자, 클라이언트 000으로 로그인합니다.
  2. 트랜잭션 SLICENSE에서 하드웨어 키를 복사합니다.
  3. SAP의 minisap 사이트에서 시스템 A4H를 골라 라이선스 파일을 받습니다.
  4. SLICENSE로 돌아와 Install을 누릅니다.
  5. 로그오프 후 DEVELOPER / 001로 다시 로그인해 SLICENSE에서 오래된 라이선스를 지웁니다.
하드웨어 키가 자꾸 바뀌면 컨테이너를 만들 때 --mac-address로 MAC 주소를 고정합니다.

M모듈 실습 환경 (MM · SD · PP · FI · CO)

위 ABAP Trial은 개발용이라 업무 모듈 설정과 데이터가 갖춰져 있지 않습니다. 구매·판매·생산·회계 흐름을 직접 돌려 보려면 업무 설정이 들어 있는 S/4HANA 시스템이 필요합니다.

방법 1 · S/4HANA 30일 체험 (SAP Cloud Appliance Library)

내 전용 시스템모든 기능과 Customizing을 직접 보고 바꿀 수 있고 SAP GUI로 접속합니다
SAP 라이선스30일간 무료 (체험 라이선스 내장)
클라우드 비용AWS · Azure · GCP 계정 필요, 켜 둔 시간당 약 3–4 USD + 소액 저장 비용
준비 시간가입 후 시스템 생성까지 약 2시간
  1. AWS · Azure · GCP 중 하나에 계정을 만듭니다.
  2. SAP Cloud Appliance Library에 가입하고 SAP S/4HANA 30일 체험(Fully-Activated Appliance)을 고릅니다.
  3. 클라우드 계정을 연결해 인스턴스를 만듭니다. 화면에 비용 예측이 나옵니다.
  4. 실습할 때만 켜고, 끝나면 반드시 중지합니다. 자동 종료 설정을 걸어 두면 안전합니다.
비용 주의 · 30일이 지나면 시스템은 정지되지만 자동으로 삭제되지는 않아 클라우드 비용이 계속 나올 수 있습니다. 더 쓰지 않으면 꼭 Terminate(삭제)하세요. 30일 뒤에도 쓰려면 SAP 제품 라이선스와 CAL 구독이 필요합니다.

방법 2 · 학교 · 기관 교육 시스템

대학의 SAP 교육 프로그램 시스템은 수업 목적으로만 쓸 수 있고 상업적 강의에는 쓸 수 없습니다.

방법 3 · 정식 교육 서버 임대

여러 수강생이 함께 쓰는 서버가 필요하면 라이선스가 정리된 교육용 시스템을 임대합니다.

시스템이 없어도 라운지의 실습 앱 시뮬레이터로 입고·송장 분개, 가격결정, MRP, 원가 배부 흐름을 먼저 익힐 수 있습니다. 시스템 실습은 그다음 단계로 하면 비용을 아낄 수 있습니다.

대안 · SAP BTP ABAP 무료 체험

PC 사양이 부족하면 SAP BTP 체험 계정으로 ADT 실습(CDS · RAP)을 할 수 있습니다. 설치는 필요 없지만, 체험 인스턴스를 모든 사용자가 함께 쓰므로 다른 사람에게 내 오브젝트가 보이고 SAP GUI 실습은 할 수 없습니다.
