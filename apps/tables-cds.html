기준일: 2026-11-14. 릴리스 상태·명칭·필드는 S/4HANA 릴리스(Cloud Public/Private, On-Premise 버전·FPS)에 따라 다릅니다. 실제 시스템에서는 SE11·ADT·Cloudification Repository Viewer로 다시 확인하세요.

  • CDS View 존재·릴리스 상태·애플리케이션 컴포넌트, 테이블의 "SAP 지정 후속 객체": SAP Cloudification Repository (github.com/SAP/abap-atc-cr-cv-s4hc) — objectReleaseInfoLatest.json(SAP Cloud ERP), objectReleaseInfo_PCELatest.json(Cloud ERP Private 최신), 2026-11-14 내려받음. 여기서 확인되지 않은 CDS는 수록하지 않았습니다.
  • SD 데이터 모델 변경(VBUK/VBUP 폐기, KONV→PRCD_ELEMENTS, V_KONV_CDS, VBTYP→VBTYPL): SAP Learning "Simplifications to the Data Model for SAP S/4HANA Sales" (SAP Note 2220005 참조).
  • MATDOC·재고 집계 테이블 프록시 CDS: SAP Community 블로그 "SAP S/4HANA Inventory Management Tables – New Simplified Data Model (NSDM)".
  • COEP/COSP/COSS 호환성 뷰: SAP Community Q&A "Replacing COEP, COSS, COSP with ACDOCA".
  • MM/SD 대외무역 미제공과 International Trade·GTS: SAP Community 블로그 "SAP S/4HANA for International Trade" (2018).
  • EIKP·EIPO 필드: leanx.eu 테이블 참조 / T604: sapstack.com / GTS /SAPSLL/CUHD·/SAPSLL/CUIT: sapdatasheet.org.
  • BAPI 존재·분류: 같은 저장소의 objectClassifications_SAP.json(Classic API 분류, 라벨 remote-enabled·transactional-consistent)과 위 두 릴리스 파일의 FUNC 객체(state·ABAP Cloud 후속 객체·애플리케이션 컴포넌트·함수그룹), 2026-11-14 내려받음. 세 파일 어디에도 없는 BAPI는 수록하지 않았습니다.
  • 원격 API 서비스명·프로토콜·엔티티 셋: SAP Cloud SDK for JavaScript VDM 패키지(npm @sap/cloud-sdk-vdm-*, SAP Business Accelerator Hub 사양으로 생성, 최종판 2022-07)의 서비스 경로와 엔티티 정의. api.sap.com은 이 작업 환경에서 접속할 수 없었습니다.
  • SOAP 분개 전기(JournalEntryCreateRequestConfirmation_In, JournalEntryBulkCreationRequest_In, SAP_COM_0002): SAP Community 블로그 "Guidelines for API Journal Entry Post" (2019).

표기 원칙: Released 배지는 위 저장소의 state=released만 표시합니다(ABAP Cloud 개발에서 사용 가능한 릴리스 API). C1/C2 같은 계약 구분과 VDM 유형(Basic/Composite)은 검증하지 못해 표기하지 않았고, C_ 접두어(=Consumption 뷰 명명 규칙)만 표기했습니다. 필드는 대표 필드이며, 확인하지 못한 필드는 "생략"으로 표시했습니다. 관세환급 같은 고객사 업무는 보통 Z 테이블로 구현하므로 여기에는 넣지 않았습니다.

BAPI · API 표기: 파라미터는 확신할 수 있는 주요 파라미터만 적었고, 그렇지 않으면 "미검증으로 생략"으로 표시했습니다. COMMIT 필요 배지는 저장소 정보가 아니라 BAPI 표준 동작(변경형 BAPI는 호출자가 BAPI_TRANSACTION_COMMIT으로 확정)에 근거한 표기이며, 확인하지 못한 BAPI에는 붙이지 않았습니다. 비즈니스 오브젝트(BOR)는 확실한 것만 적었습니다. 실행 샘플: 주요 BAPI 17개와 OData 생성 3종(판매오더·구매오더·자재문서)은 전체 코드, 나머지는 호출 패턴입니다. 회사코드 1010·자재 TG11 등은 S/4HANA 데모 데이터 형식의 예시 값이며, 실행 전 SE37 테스트로 내 시스템에서 먼저 확인하세요. 원격 API의 최신 릴리스·폐기(deprecated) 상태와 V4 후속 서비스 여부는 검증하지 못했으므로 사용 전에 SAP Business Accelerator Hub에서 확인하세요.
